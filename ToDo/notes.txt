comando para iniciar projeto: npm init -y

No package.json, no "type", trocar o "common" por "module"(Se não tiver type, pode adicionar)

Instalar: express, mongoose, cors, dotenv -> npm install ...

Instalar para desenvolvimento: nodemon -> npm install --save-dev ... ou npm install -D ...

Para subir o projeto, deletar a pasta "node_modules" ou fazer um arquivo .gitignore. Para reinstalar, digitar o comando npm install ou npm i

-- Desenvolvimento

Criar arquivo index.js

Criar arquivo conn.js na pasta db

Criar um arquivo na pasta Models

Criar um arquivo na pasta Controllers

Criar um arquivo na pasta Routes. Caso existir mais que um Controller. É possível colocar todas as rotas em um único arquivo ou criar arquivos separados.
Recomendado criar um para cada
Importar Routes para o index.js e ligar o express com as rotas

Instalação do Swagger:
npm install swagger-ui-express
npm install -D swagger-autogen

Alterar a parte "scripts" no package.json para incluir o swagger

Criar arquivo na raiz da pasta Backend chamado "swagger.js"

Para rodar o projeto:
npm run swagger

Alterar o index inserindo o Swagger

Para subir o Backend:
npm start
